# DEFINITION_OF_DONE — Définition de terminé

> **Statut :** `APPLICABLE`

Une tâche n’est terminée que lorsque :

- l’objectif, le périmètre et les critères d’acceptation sont satisfaits ;
- les sources et hypothèses sont vérifiées ou explicitement ouvertes ;
- les changements sont atomiques, relus et traçables ;
- les contrôles applicables et la non-régression sont documentés ;
- les documents canoniques, identifiants et artefacts existants sont préservés ;
- les preuves sont conservées ;
- `STATUS.md`, `SUIVI.md`, `TODO.md`, `WORK_LOG.md`, `HANDOFF.md` et `NEXT_ACTION.md` sont cohérents ;
- aucune validation humaine requise n’est inventée ;
- aucune branche, réécriture, fusion ou opération de production non autorisée n’a eu lieu.

Un statut `BLOCKED` documenté vaut mieux qu’une clôture fictive.
