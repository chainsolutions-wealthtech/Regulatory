# BRANCH_POLICY — Politique spécifique du dépôt

> **Statut :** `APPLICABLE`  
> **Autorité :** `README.md`, `AGENTS.md` et `DEC-011`.

## Règles obligatoires

- aucune nouvelle branche ;
- aucun changement de branche sans instruction explicite ;
- `main` reste utilisée si aucune autre branche existante n’est désignée ;
- aucun force-push ;
- aucune réécriture d’historique ;
- aucune suppression de branche ;
- aucune PR nécessitant la création d’une branche ;
- aucune fusion ou déploiement dans une mission documentaire.

Cette politique particulière prévaut sur toute recommandation générique du kit. Elle ne peut être modifiée silencieusement.

## Contrôle

Avant et après chaque intervention, enregistrer la branche et le commit. Toute action exigeant une nouvelle branche doit s’arrêter et être escaladée.

## Checklist

- [ ] branche initiale relevée ;
- [ ] branche finale identique ;
- [ ] aucune branche créée ;
- [ ] aucun force-push ;
- [ ] historique préservé.
