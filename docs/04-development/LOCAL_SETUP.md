# LOCAL_SETUP — Installation locale

> **Statut :** `À DÉTERMINER`

Aucun code applicatif, runtime, gestionnaire de paquets, base ou commande de démarrage n’est validé. Il est interdit d’inventer des commandes exécutables.

## Contenu à compléter après décision technique

- prérequis et versions ;
- clonage et branche existante à conserver ;
- configuration locale sans secrets dans Git ;
- variables d’environnement documentées par noms, jamais valeurs ;
- initialisation des données de test ;
- commandes de build, test, lint et démarrage ;
- résolution des erreurs fréquentes ;
- nettoyage et rollback.

## Règles

Ne jamais utiliser des données de production comme données de développement. Les exemples doivent être synthétiques ou anonymisés. Toute modification de setup met à jour CI/CD et sécurité.
