# CODING_STANDARDS — Standards de code

> **Statut :** `À DÉTERMINER`

Aucune stack applicative n’est validée. Les standards spécifiques au langage ne doivent pas être inventés.

## Principes indépendants de la stack

- lisibilité, types et erreurs explicites ;
- fonctions et modules à responsabilité claire ;
- identifiants canoniques stables ;
- déterminisme du moteur documentaire ;
- aucune donnée réglementaire codée en dur sans source/version ;
- logs sans secret ni donnée personnelle inutile ;
- migrations et compatibilité documentées ;
- tests de non-régression pour chaque changement significatif ;
- dépendances minimales et versionnées.

## Activation

Après décision de stack, compléter avec formatage, lint, types, structure, performance, sécurité, tests et exemples approuvés. Toute évolution structurante passe par revue et ADR.
