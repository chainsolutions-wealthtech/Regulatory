# PR_POLICY — Politique des pull requests

> **Statut :** `À DÉTERMINER`

La politique du dépôt interdit de créer une branche pour ouvrir une PR. Aucune PR n’est requise dans LOOP-GOV-001. Une utilisation future n’est possible qu’avec une branche existante explicitement désignée et une autorisation du propriétaire.

`À DÉFINIR — information non fournie ou non vérifiée à ce stade du projet.`

Toute PR autorisée doit fournir tâche, état initial, diff, risques, tests, documentation, rollback et preuves de non-régression. Elle ne doit jamais être présentée comme validation juridique ou réglementaire.

## Checklist

- [ ] aucune branche créée ;
- [ ] autorisation explicite présente ;
- [ ] preuves et rollback décrits ;
- [ ] aucun secret ;
- [ ] aucune validation inexistante déclarée.
