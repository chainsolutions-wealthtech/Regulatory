# CODE_REVIEW — Revue de code et de configuration

> **Statut :** `À DÉTERMINER`

Aucun code applicatif n’existe encore. Ce cadre devient applicable dès le premier changement de code, schéma, règle exécutable ou générateur.

## Revue minimale

- objectif et tâche ;
- architecture et décisions ;
- exactitude des sources réglementaires ;
- compatibilité des identifiants et données ;
- erreurs, sécurité, performance et observabilité ;
- tests et non-régression ;
- migrations et rollback ;
- documentation et preuves ;
- absence de secret.

## Règles

Le réviseur ne valide pas juridiquement une règle hors de son rôle. Les conflits doivent être explicités. Une IA peut assister la revue mais pas remplacer l’approbateur humain.

La politique de PR reste soumise à `PR_POLICY.md` et à l’interdiction de créer une branche.
