# MOBILE — Application mobile

> **Statut :** `À DÉTERMINER`

Aucune application mobile n’est décidée.

## Questions préalables

Besoin utilisateur, fonctionnalités, données hors ligne, authentification, pièces jointes, notifications, accessibilité, sécurité de l’appareil, stores, mises à jour et support.

## Règles

- ne pas créer un modèle de données distinct ;
- utiliser les mêmes APIs et données canoniques si une architecture les prévoit ;
- limiter le stockage local sensible ;
- revue sécurité et vie privée ;
- tests multi-plateformes ;
- procédure de révocation et de mise à jour.

Périmètre, technologies et responsables : `À DÉFINIR — information non fournie ou non vérifiée à ce stade du projet.`
