# RELEASE_CRITERIA — Critères de release

> **Statut :** `À DÉTERMINER`

Aucune release applicative n’existe encore. Avant activation, il faudra définir version, périmètre, environnements, responsables, tests, sécurité, données, rollback et approbations.

## Critères minimaux futurs

- corpus et pack réglementaire identifiés ;
- migrations et compatibilité vérifiées ;
- tests et contrôles réussis ;
- aucun blocage critique ;
- documentation et notes de version ;
- sauvegarde et rollback testés ;
- approbations métier, conformité, juridique, sécurité et opérations selon RACI ;
- aucune présentation comme visa réglementaire.

Les informations opérationnelles restent `À DÉFINIR — information non fournie ou non vérifiée à ce stade du projet.`
