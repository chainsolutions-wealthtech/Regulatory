# USE_CASES — Cas d’usage

> **Statut :** `APPLICABLE`

## Cas V1

1. créer un prospectus FCP à partir d’un profil SGO prérempli ;
2. dupliquer un fonds en confirmant les différences ;
3. importer un prospectus existant avec provenance et confirmation ;
4. mettre à jour un prospectus publié à partir des écarts ;
5. générer table de concordance, rapports et dossier de preuves ;
6. revoir et approuver les sections selon les rôles ;
7. analyser l’impact d’une évolution réglementaire.

## Modèle

Pour chaque cas : acteurs, préconditions, déclencheur, parcours nominal, alternatives, erreurs, données, règles, preuves, sorties, sécurité et critères d’acceptation.

## Interdictions

Ne pas présenter l’export comme agréé ou visé. Ne pas considérer une extraction ou une suggestion IA comme vérifiée sans source ou revue.
