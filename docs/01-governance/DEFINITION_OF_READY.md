# DEFINITION_OF_READY — Définition de prêt

> **Statut :** `APPLICABLE`

Une tâche est prête lorsque :

- le besoin et la source sont compris ;
- l’objectif, le périmètre et les non-objectifs sont définis ;
- les documents canoniques et l’existant ont été lus ;
- les dépendances, hypothèses, risques et questions sont recensés ;
- les critères d’acceptation, contrôles, preuves et rollback sont définis ;
- les validations humaines et responsabilités nécessaires sont identifiées ;
- aucune information essentielle n’est inventée ;
- l’action peut être réalisée sur la branche existante sans opération Git interdite.

Une tâche non prête reste dans `BACKLOG.md`, `OPEN_QUESTIONS.md` ou avec un statut bloqué dans `TODO.md`.

## Checklist

- [ ] besoin sourcé ;
- [ ] impact analysé ;
- [ ] dépendances disponibles ;
- [ ] critères vérifiables ;
- [ ] prochaine action exécutable.
