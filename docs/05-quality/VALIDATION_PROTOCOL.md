# VALIDATION_PROTOCOL — Protocole de validation

> **Statut :** `APPLICABLE`

## Séquence

1. définir objet, version, source et critères ;
2. geler les entrées ;
3. exécuter contrôles structurels, métier, réglementaires, interdocumentaires et de preuve ;
4. enregistrer résultats, anomalies et limites ;
5. obtenir les revues humaines requises ;
6. distinguer `STRUCTURALLY_VALIDATED`, `LEGAL_REVIEW_PENDING`, `APPROVED` et autres statuts ;
7. conserver manifeste, date, acteurs et empreintes.

## Règles

Une validation ne peut pas dépasser son périmètre. L’IA ne transforme pas une validation automatisée en avis juridique. Un échec ou une source non vérifiée reste visible.

## Checklist

- [ ] critères et entrées gelés ;
- [ ] versions enregistrées ;
- [ ] contrôles reproductibles ;
- [ ] limites explicites ;
- [ ] approbations réelles ;
- [ ] preuve archivée.
