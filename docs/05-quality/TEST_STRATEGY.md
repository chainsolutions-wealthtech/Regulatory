# TEST_STRATEGY — Stratégie de test

> **Statut :** `APPLICABLE`

## Niveaux attendus

- tests de structure des sources, exigences, matrices et schémas ;
- tests unitaires des règles et conditions ;
- tests du graphe de questions ;
- tests de génération déterministe et snapshots ;
- tests de cohérence interdocumentaire ;
- tests de sécurité, performance et accessibilité selon applicabilité ;
- recette réglementaire sur prospectus exemples, sans les traiter comme norme.

## État actuel

Les commandes, frameworks et environnements sont `À DÉFINIR — information non fournie ou non vérifiée à ce stade du projet.` La validation structurelle existante ne remplace pas ces tests.

## Preuves

Chaque exécution enregistre version, entrée, environnement, résultat, anomalies et artefacts. Un test supprimé ou contourné pour faire passer une modification est interdit.

## Checklist

- [ ] couverture liée aux risques ;
- [ ] données de test non sensibles ;
- [ ] résultats reproductibles ;
- [ ] échecs conservés ;
- [ ] revue humaine lorsque nécessaire.
