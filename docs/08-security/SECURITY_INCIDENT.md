# SECURITY_INCIDENT — Incident de sécurité

> **Statut :** `À DÉTERMINER`

## Déclencheurs futurs

Accès non autorisé, secret exposé, altération de source ou preuve, fuite de données, malware, vulnérabilité exploitée ou comportement anormal.

## Réponse

Préserver les faits, limiter l’impact avec des actions autorisées, protéger les preuves, notifier les rôles compétents, évaluer données et obligations, restaurer, vérifier, documenter et suivre les actions.

## Règles

- aucun détail sensible dans un canal public ;
- aucune action destructive non approuvée ;
- chronologie et décisions enregistrées ;
- coordination juridique, conformité et vie privée ;
- postmortem et test de non-régression.

Contacts, délais et outils : `À DÉFINIR — information non fournie ou non vérifiée à ce stade du projet.`
