# AI_HANDOFF — Transmission entre agents

> **Statut :** `APPLICABLE`

## Contenu obligatoire

Dépôt, branche, commits, objectif, état initial, travail réalisé, fichiers touchés, décisions, contrôles, preuves, échecs, limites, questions, risques et prochaine action unique.

## Règles

- le handoff doit être vérifiable dans Git ;
- distinguer terminé, en cours, bloqué et proposé ;
- ne pas attribuer à la boucle les travaux antérieurs ;
- ne pas transmettre de secret ou donnée personnelle inutile ;
- indiquer les validations encore manquantes ;
- renvoyer vers `HANDOFF.md`, `STATUS.md`, `WORK_LOG.md` et `NEXT_ACTION.md`.

Un agent repreneur doit réconcilier le handoff avec l’arborescence et les commits avant de continuer.
