# RELEASE_PROCESS — Processus de release

> **Statut :** `À DÉTERMINER`

## Processus futur

1. qualifier le périmètre et geler les versions ;
2. vérifier sources, schémas, migrations et dépendances ;
3. exécuter les portes de qualité ;
4. produire les artefacts et empreintes ;
5. obtenir les approbations ;
6. déployer selon la politique ;
7. vérifier l’état et les métriques ;
8. publier notes et manifeste ;
9. conserver rollback et preuves.

## Contraintes

Aucune release ou déploiement n’est autorisé dans LOOP-GOV-001. Les outils, environnements et responsabilités sont `À DÉFINIR — information non fournie ou non vérifiée à ce stade du projet.`

Toute release affectant le pack réglementaire doit enregistrer les versions des textes, exigences, clauses, modèles et données.
