# BUILD — Construction applicative

> **Statut :** `À DÉTERMINER`

Aucun runtime, framework ou outil de build n’est défini.

## Contenu futur

- prérequis et versions ;
- commandes reproductibles ;
- dépendances verrouillées ;
- génération des artefacts ;
- validation des schémas et ressources ;
- empreintes et provenance ;
- échecs et diagnostics ;
- nettoyage ;
- sécurité de la chaîne de build.

## Règles

Le build doit être déterministe et ne récupérer aucune règle réglementaire non versionnée à l’exécution. Les secrets sont injectés hors Git. Les artefacts doivent être reliés au commit, aux versions des packs, clauses et modèles.

Les commandes sont `À DÉFINIR — information non fournie ou non vérifiée à ce stade du projet.`
