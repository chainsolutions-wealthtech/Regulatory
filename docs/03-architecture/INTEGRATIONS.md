# INTEGRATIONS — Intégrations externes

> **Statut :** `À DÉTERMINER`

Aucune intégration applicative externe n’est encore validée. Les sources réglementaires, référentiels, systèmes de société de gestion, stockage documentaire, signature, identité ou services tiers devront être qualifiés séparément.

## Fiche obligatoire

Système, propriétaire, finalité, données échangées, contrat/version, authentification, disponibilité, sécurité, vie privée, coûts, dépendance, audit, erreurs, reprise, tests, dépréciation et plan de sortie.

## Règles

- aucun secret dans la documentation ;
- moindre privilège ;
- validation des données importées ;
- conservation de la provenance ;
- aucune dépendance propriétaire non documentée ;
- revue juridique et sécurité lorsque nécessaire.

Toute intégration crée une entrée dans `DEPENDENCIES.md`, `THIRD_PARTY_SERVICES.md`, les risques et, si structurante, une ADR.
