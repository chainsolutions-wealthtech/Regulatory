# API_CONTRACTS — Contrats d’API

> **Statut :** `À DÉTERMINER`

Aucune API applicative ni protocole technique n’est encore validé. Ce fichier définit le cadre à utiliser si une API est décidée.

## Contenu obligatoire futur

- objectifs et consommateurs ;
- endpoints ou messages ;
- schémas versionnés ;
- authentification et autorisation ;
- validation, erreurs et idempotence ;
- pagination, quotas et compatibilité ;
- audit, données sensibles et rétention ;
- tests de contrat, migration et dépréciation.

## Interdictions

Ne pas inventer d’URL, de technologie, de clé, de secret ou de contrat opérationnel. Toute proposition doit être reliée au modèle canonique et à une ADR.

## Checklist

- [ ] applicabilité décidée ;
- [ ] consommateurs identifiés ;
- [ ] schémas et sécurité revus ;
- [ ] compatibilité et tests ;
- [ ] documentation publique/privée séparée.
