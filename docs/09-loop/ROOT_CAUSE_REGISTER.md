## Méthode

Distinguer symptôme, cause immédiate, cause racine et facteurs organisationnels. Utiliser faits, chronologie et tests; éviter les conclusions personnelles non prouvées.

## Règles

- aucune cause inventée ;
- statut `HYPOTHESIS` tant que non vérifiée ;
- action liée à un test ou une modification mesurable ;
- revue juridique/sécurité lorsque le domaine l’exige ;
- historique conservé si une cause est révisée.

Les conclusions alimentent `LESSONS_LEARNED.md`, les règles, les checklists et les tests de non-régression.
