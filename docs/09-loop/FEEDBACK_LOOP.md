# FEEDBACK_LOOP — Boucle de retour

> **Statut :** `APPLICABLE`

## Processus

Observation → qualification → action bornée → mesure → décision → documentation → reprise.

Chaque retour conserve sa provenance. Il est distingué d’une source normative et dirigé vers `BACKLOG.md`, `TODO.md`, `FAILURE_REGISTER.md`, `OPEN_QUESTIONS.md` ou `LESSONS_LEARNED.md`.

## Règles

- séparer fait, opinion, pratique observée et obligation sourcée ;
- définir avant l’action un résultat mesurable ;
- conserver les résultats négatifs ou inconclusifs ;
- documenter les risques et dépendances ;
- obtenir une revue humaine pour les conclusions sensibles ;
- ne pas modifier silencieusement une décision existante.

## Checklist

- [ ] source et contexte ;
- [ ] qualification ;
- [ ] mesure ;
- [ ] résultat factuel ;
- [ ] tâche, décision ou leçon mise à jour.
