# LESSONS_LEARNED — Retours d’expérience

> **Statut :** `APPLICABLE`

## Leçons initiales

1. Un kit documentaire générique doit être adapté aux documents canoniques historiques, pas les remplacer.
2. La multiplication des fichiers exige une hiérarchie de vérité, des adaptateurs et des contrôles de liens.
3. Une validation structurelle ne vaut jamais validation juridique.
4. Les informations inconnues doivent rester explicitement inconnues.
5. Les artefacts machine-readable doivent être protégés d’une réorganisation purement documentaire.
6. La politique Git spécifique du dépôt doit prévaloir sur les habitudes génériques des outils.
