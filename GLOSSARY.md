# GLOSSARY — Glossaire du projet

> **Statut :** `APPLICABLE`

| Terme | Définition dans ce dépôt |
|---|---|
| AMF-UMOA | Autorité régionale compétente, anciennement CREPMF. |
| FCP | Fonds Commun de Placement. |
| OPC/OPCVM | Organisme de placement collectif / organisme de placement collectif en valeurs mobilières selon le contexte sourcé. |
| Exigence | Obligation atomisée reliée à une source réglementaire versionnée. |
| Champ canonique | Donnée structurée unique alimentant plusieurs documents et contrôles. |
| Clause | Formulation juridique versionnée, conditionnelle et soumise à approbation. |
| Couverture | Emplacement où une exigence est satisfaite : prospectus, règlement, annexe ou non-applicabilité justifiée. |
| Loop Engineering | Boucle de travail fondée sur état réel, action bornée, preuves, documentation et handoff. |
| Adaptateur | Fichier court renvoyant vers un document canonique historique. |
| ADR | Architecture Decision Record ou décision structurante détaillée. |

Toute définition réglementaire doit être reliée à une source. Les termes ambigus sont ajoutés à `OPEN_QUESTIONS.md`.
