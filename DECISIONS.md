# DECISIONS — Index des décisions

> **Statut :** `APPLICABLE`  
> **Autorité :** ce fichier est un index; il ne remplace aucun registre existant.

## Documents canoniques

- `docs/DECISIONS.md` conserve les décisions historiques `DEC-*` déjà validées.
- `docs/adr/` contient les décisions structurantes détaillées créées à partir de l’adoption du Loop Engineering.
- `docs/adr/README.md` définit la convention.

## Règle

Ne jamais recopier intégralement une décision dans plusieurs fichiers. Une ADR référence les décisions historiques concernées et explique contexte, conséquences, risques, migration et rollback. Une décision remplacée est marquée `SUPERSEDED`, jamais supprimée.
