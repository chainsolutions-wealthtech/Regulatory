# NON_GOALS — Non-objectifs actifs

> **Statut :** `APPLICABLE`

LOOP-GOV-001 ne vise pas à :

- recommencer le projet ;
- remplacer l’architecture ou les décisions historiques ;
- modifier les artefacts réglementaires non Markdown ;
- développer l’application ;
- choisir la stack, la base ou les environnements ;
- créer une branche, une PR, une fusion ou un déploiement ;
- valider juridiquement les textes, mappings ou clauses ;
- importer des modèles ou décisions d’un autre projet ;
- présenter un document comme approuvé ou visé.

Les non-objectifs produit différés sont décrits dans `SCOPE.md`, `ROADMAP.md` et `BACKLOG.md`.
